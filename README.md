## 阅读建议

已有 C/C++ 基础时可先快速阅读前 3 章，再重点练习 NumPy、Tensor 与环境接口。

这是以 Markdown 为主的学习资料仓库，阅读本身无需安装依赖。章节中的示例可单独练习，
具体工具、软件版本和硬件条件应按对应章节核对。
